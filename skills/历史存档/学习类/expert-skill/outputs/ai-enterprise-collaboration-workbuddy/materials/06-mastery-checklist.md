# 06 达标清单：资深专家自证

> 完成下列项并能在他人面前讲解，视为达到本领域 L5 入门。建议证据链：文档链接 / 评审记录 / POC 数据。

## 知识层（必须全勾）

- [ ] 能无稿讲解 Agent 工作台 vs 聊天机器人差异（≤3 分钟）
- [ ] 能画出 MCP 在三层栈中的位置
- [ ] 能解释 WorkBuddy 个人版与企业版核心差异
- [ ] 能对比 WorkBuddy / 钉钉悟空 / 飞书 Aily 的选型场景（各 1 句）
- [ ] 能说明 Skill、Expert、Expert Team 三者关系

## 判断层（至少 4/5）

- [ ] 独立完成 1 次场景分级矩阵（风险×频率）
- [ ] 用 Build/Buy/Configure 框架给过 1 个真实建议
- [ ] 识别过 1 个「超级个体陷阱」并提出组织解法
- [ ] 设计过 1 条 HITL 规则并说明为何不能全自动
- [ ] 评审过 1 份他人方案并使用 `04-review-rubrics.md` 出报告

## 编排层（至少 3/4）

- [ ] 设计过 1 个多步 Agent 工作流（含失败恢复）
- [ ] 写过或评审过 1 个 Skill 的 frontmatter + 约束
- [ ] 配置或文档化过 1 个 MCP/Connector 权限边界
- [ ] 定义过 3 个试点指标（成功率/介入率/满意度等）

## 带人层（至少 2/3）

- [ ] 带 1 人完成从场景卡片到 POC 清单
- [ ] 主持过 1 次 Skill/方案评审会
- [ ] 写过 1 页「团队 AI 协作规范」草案

## 最终答辩（自选 1 题，15 分钟）

1. 若你是 WorkBuddy PM，Enterprise 版下一季度最该做的一个能力是什么？为什么？
2. 某客户要「全自动竞品监控 + 自动发投资人」，你如何说不并给替代方案？
3. 设计一个「专家.skill」生成器在企业场景的治理门禁。
