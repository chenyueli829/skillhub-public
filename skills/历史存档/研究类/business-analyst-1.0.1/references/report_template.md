## HTML 报告格式规范

彭梅偏好：奶油底 `#faf8f5` + 衬线字体 + 卡片布局 + 浅色主题

### 配色
- 背景：`#faf8f5`
- 卡片背景：`#ffffff`
- 标题色：`#1a1a1a`
- 强调色：`#2c5f2e`（深绿，适合战略感）
- 次要文字：`#666666`
- 边框/分割线：`#e8e0d8`
- 指标高亮：`#f0f9f0`

### 字体
```css
font-family: 'Georgia', 'Noto Serif SC', serif;
```

### 布局结构
```html
<div class="report-container">
  <!-- 封面卡片：公司名、行业、报告日期 -->
```

## 报告写作规范

### 风格要求
- 去 AI 化：避免"值得注意的是"、"需要指出"等模板语
- 具体数据优先：尽量用数字替代形容词
- 场景化表达：用具体业务场景说明抽象策略
- 简洁段落：每段不超过4句，快速传递关键信息

### 新闻整合规范
- 每条新闻来源标注（来源：路透社/财经/Bloomberg/官方PR）
- 时间标注（如：2025年3月）
- 与商业模式的关联解读（这个动作印证/挑战了哪个要素？）

### 指标缺失处理
- 明确标注"数据未公开"
- 提供替代参考（如：同行业均值、分析师预测）
- 不捏造数据，不模糊表述

## 综合研判写作框架

三位一体解读 = **战略一致性** + **策略执行质量** + **指标印证**

```
[战略] 该公司核心战略是XXX，商业模式本质是XXX模式。
[策略] 近期动作（新闻A、新闻B）表明公司正在XXX方向加速/调整/收缩。
[指标] 这一策略已在XXX指标上体现：[数据]，同比/环比XXX。
[研判] 战略与近期动作[一致/存在分歧]。主要风险点在于XXX，关键机遇在于XXX。
```
