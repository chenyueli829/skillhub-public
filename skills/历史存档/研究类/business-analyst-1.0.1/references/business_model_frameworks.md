# 商业模式分析框架库

整合自：Business Model Generation (Osterwalder)、Business Model Navigator (Gassmann)、Business Model Shifts (van der Pijl) 等经典著作。

---

## 一、商业模式画布（Business Model Canvas）

> 来源：Osterwalder & Pigneur《商业模式新生代》

### 9要素框架

| 模块 | 英文 | 核心问题 |
|------|------|----------|
| 客户细分 | Customer Segments | 为谁创造价值？最重要的客户是谁？ |
| 价值主张 | Value Propositions | 为客户解决什么问题/满足什么需求？ |
| 渠道通路 | Channels | 如何接触并向客户传递价值主张？ |
| 客户关系 | Customer Relationships | 与每个客户群建立何种关系？ |
| 收入来源 | Revenue Streams | 客户愿意为什么付钱？如何付钱？ |
| 核心资源 | Key Resources | 提供价值主张需要哪些关键资源？ |
| 关键业务 | Key Activities | 提供价值主张需要哪些关键活动？ |
| 重要伙伴 | Key Partners | 谁是核心合作伙伴？ |
| 成本结构 | Cost Structure | 主要成本是什么？哪些最贵？ |

### 商业模式类型（按价值主张分）
- **长尾模式**：销售大量小众产品（Amazon、Netflix）
- **多边平台**：连接两个或多个客户群（Google、Airbnb）
- **免费模式**：一个群体免费，另一个群体付费（Facebook、LinkedIn）
- **开放式模式**：通过与外部合作系统化创造和利用知识（P&G、GlaxoSmithKline）

## 二、商业模式转型6方向（Business Model Shifts）

> 来源：van der Pijl《Business Model Shifts》

| 转型维度 | 方向 | 典型案例 |
|----------|------|----------|
| 产品→服务 | 从销售产品变为提供服务 | Rolls-Royce"按飞行小时收费" |
| 股东→利益相关方 | 从短期利润到长期价值 | Patagonia、Interface |
| 实体→数字 | 数字化交付与体验 | Netflix、Spotify |
| 功能→平台 | 成为连接者 | Uber、Airbnb |
| 规模→生态 | 构建合作伙伴网络 | Apple App Store、WeChat |
| 内部→开放 | 开放创新与众包 | LEGO Ideas、P&G Connect+Develop |

## 三、55种商业模式模式（Business Model Navigator）

> 来源：Gassmann《The Business Model Navigator》

### 最常见的核心模式（按频率排序）

**收入模式类**
- **订阅制 Subscription**：按月/年固定收费，稳定现金流（Netflix、Spotify、SaaS）
- **免费增值 Freemium**：基础免费+付费升级（Spotify、LinkedIn、Dropbox）
- **按使用量 Pay-Per-Use**：用多少付多少（AWS、Twilio）
- **平刀/打包 Flat Rate**：无限量固定价（Buffet、无限流量套餐）
- **附加收费 Add-on**：核心低价+配件高利润（Gillette、打印机/墨盒）

**平台模式类**
- **多边平台 Multi-Sided Platform**：连接买卖双方（Airbnb、eBay、微信）
- **长尾 Long Tail**：服务大量小众需求（Amazon、YouTube）
- **用户设计 User Design**：用户参与创造（Threadless、Lego Ideas）

**竞争壁垒类**
- **锁定 Lock-In**：转换成本高（Apple生态、Adobe、Oracle）
- **跨界销售 Cross-Selling**：在核心业务上叠加销售（Amazon、银行）
- **反向创新 Reverse Innovation**：低端切入再升级（小米、Haier）

**运营模式类**
- **解决方案提供商 Solution Provider**：整合所有问题的完整解（IBM、SAP）
- **白标 White Label**：为他人生产品牌产品（Foxconn、代工厂）
- **大规模定制 Mass Customization**：标准化流程+个性化结果（Nike ID、Dell）
- **众包 Crowdsourcing**：利用外部人群（Wikipedia、Kickstarter）
- **特许经营 Franchising**：复制成功模式（麦当劳、7-11）

## 四、价值主张分析维度

分析公司价值主张时，重点关注以下维度：

### 功能维度（Functional）
- 性能提升（Better performance）
- 便利性（Convenience）
- 价格降低（Price reduction）
- 风险降低（Risk reduction）
- 可及性（Accessibility）

### 情感维度（Emotional）
- 品牌/身份认同（Brand/Identity）
- 设计感（Design）
- 新颖体验（Novelty）

### 社会维度（Social）
- 社会地位（Social status）
- 归属感（Belonging）
- 可持续/使命感（Sustainability/Mission）

## 五、商业模式分析的四维框架（Who-What-How-Why）

> Gassmann 圣加仑模型的核心

- **Who**（谁）：目标客户是谁？如何细分？
- **What**（什么）：提供什么价值主张？
- **How**（如何）：通过什么价值链/能力/合作创造和交付？
- **Why**（为何）：如何盈利？收益模型是什么？

## 六、竞争策略与商业模式结合

参考波特五力 + 差异化/成本领先：

| 战略类型 | 核心逻辑 | 配套商业模式 |
|----------|----------|-------------|
| 成本领先 | 规模经济/运营效率 | 平台、长尾、大规模定制 |
| 差异化 | 独特价值/品牌溢价 | 锁定、订阅、解决方案 |
| 聚焦 | 深耕垂直市场 | 用户设计、多边平台 |

## 七、商业模式演化阶段

企业通常经历以下阶段（可用于判断公司所处位置）：

1. **产品阶段**：卖单一产品，交易为主
2. **服务化阶段**：产品+服务打包，提高粘性
3. **平台阶段**：连接多方，赚网络效应的钱
4. **生态阶段**：成为基础设施，构建护城河
