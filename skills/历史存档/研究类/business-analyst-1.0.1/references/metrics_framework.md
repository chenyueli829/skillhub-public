# 商业模式指标体系设计框架

基于北极星指标（NSM）理论 + 数据分析层级结构设计。

---

## 一、北极星指标选取原则

**北极星指标（North Star Metric, NSM）** 是能最好反映公司核心价值主张的单一度量。

### 选取标准
1. **反映核心价值交付**：客户从你的产品/服务中真正获得价值的瞬间
2. **可量化**：有明确的计量单位
3. **可驱动**：上下游团队都能影响它
4. **领先指标**：早于收入变化而变化

### 各类商业模式的典型北极星指标

| 商业模式类型 | 典型北极星指标 | 说明 |
|-------------|--------------|------|
| 内容/媒体平台 | 每日活跃用户（DAU）/ 内容消费时长 | Netflix：月均观看时长 |
| SaaS / 订阅 | 付费用户数 / NRR（净收入留存率） | Salesforce：活跃合同数 |
| 电商 / 交易平台 | GMV（总交易额）/ 订单量 | Amazon：购买用户数 |
| 双边市场 / 出行 | 完成交单量（completed rides/bookings） | Uber：每周完成单量 |
| B2B SaaS | 每用户每周核心功能使用次数 | Slack：每天发送消息数 |
| 社交网络 | 连接数 / 互动用户数 | Facebook：MAU |
| 金融科技 | 资产规模（AUM）/ 活跃交易账户 | 支付宝：活跃支付用户 |
| 广告平台 | 广告主收入 / 流量变现效率 | Google：广告收入 |
| 硬件+服务 | 设备激活量 + 服务渗透率 | Apple：设备装机量 |
| 本地生活 | 用户复购率 / 履约订单量 | 美团：年活跃买家数 |

## 二、三层指标体系结构

### 第一层：北极星指标（1个）
- 代表公司最核心的价值交付
- 高管层关注，定义企业方向

### 第二层：驱动指标（3-6个）
- 直接驱动北极星指标的关键杠杆
- 通常对应业务增长公式的拆解
- 各业务线/产品负责人关注

### 第三层：过程指标（若干）
- 支撑二级指标的执行层面度量
- 运营团队日常跟踪
- 可追溯到具体动作

## 三、按商业模式类型的指标树模板

### 🛒 电商 / 交易平台

```
[北极星] GMV（总交易额）
│
├── [二级] 买家数 × 购买频次 × 客单价
│   ├── 新增买家数（拉新）
│   ├── 复购买家占比（留存）
│   ├── 客单价变化趋势
│   └── 购买频次/月
│
├── [二级] 商品供给质量
│   ├── SKU数量
│   ├── 爆款商品转化率
│   └── 缺货率
│
└── [二级] 转化漏斗效率
    ├── 访客→加购转化率
    ├── 加购→下单转化率
    └── 下单→支付成功率
```

### 📱 SaaS / 订阅制

```
[北极星] ARR（年度经常性收入）或 NRR（净收入留存率）
│
├── [二级] 获客
│   ├── 新签客户数
│   ├── CAC（客户获取成本）
│   └── 销售转化率
│
├── [二级] 留存 / 扩张
│   ├── 月留存率 / Churn Rate
│   ├── NPS（净推荐值）
│   └── Expansion MRR（增购收入）
│
└── [二级] 使用深度
    ├── DAU/MAU 比值（粘性）
    ├── 核心功能渗透率
    └── 功能使用广度
```

### 🚀 互联网平台（双边市场）

```
[北极星] 完成交易量 / 撮合成功率
│
├── [二级] 供给侧
│   ├── 活跃供给方数量
│   ├── 供给充足率（需求满足率）
│   └── 供给质量分（评分/履约率）
│
├── [二级] 需求侧
│   ├── 活跃用户数（DAU/MAU）
│   ├── 用户留存率（D7/D30）
│   └── 用户满意度（CSAT/评分）
│
└── [二级] 平台效率
    ├── 匹配效率（响应时间/接单率）
    ├── 单位经济（单笔交易利润）
    └── 流量获取成本（CAC）
```

### 🏭 传统制造 / 消费品

```
[北极星] 市场份额 / 收入增速
│
├── [二级] 品牌指标
│   ├── 品牌知名度
│   ├── 品牌首选率
│   └── NPS / 品牌净推荐值
│
├── [二级] 渠道指标
│   ├── 渠道覆盖率（铺货率）
│   ├── 终端动销率
│   └── 渠道商库存健康
│
└── [二级] 产品力指标
    ├── 新品贡献率
    ├── 爆款占比
    └── 复购率
```

### 💰 金融 / Fintech

```
[北极星] AUM（管理资产规模）/ 活跃交易用户数
│
├── [二级] 获客
│   ├── 新增注册用户
│   ├── KYC通过率
│   └── 首笔交易转化率
│
├── [二级] 活跃度
│   ├── MAU（月活用户）
│   ├── 人均交易笔数
│   └── 功能使用深度
│
└── [二级] 风险与收益
    ├── 不良贷款率（NPL）
    ├── 净息差（NIM）
    └── ROE（净资产收益率）
```

## 四、指标数据来源优先级

在分析实际公司时，按以下顺序填充指标数据：

1. **官方财报**：年报/季报中的关键运营指标（KPI disclosure）
2. **投资者关系页面**：业绩发布会PPT、业绩指引
3. **近期新闻/公告**：CEO讲话、战略发布、融资PR中提到的数据
4. **行业报告**：艾瑞、易观、IDC 等第三方数据
5. **实时搜索**：通过 Web Search 补充最新数据

## 五、指标填写规范

在报告中引用数据时注意：

- 标注数据时间（如：2024Q3、2024年全年）
- 标注数据来源（如：公司财报、路透社报道）
- 对于缺失数据，标注"待补充"或"数据未公开"
- 优先使用同比增速而非绝对值（更直观体现趋势）
- YoY（同比）、QoQ（环比）需明确区分
