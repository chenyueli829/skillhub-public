# Character Reference Sheet

## Preset: ohmsha (Doraemon-style educational manga)

### 大雄 Nobita — 读者替身 / 深度龙虾用户
- 10岁男孩，圆眼镜，黑色短发，黄衬衫，深蓝短裤
- 表情丰富：困惑螺旋眼、Aha 时刻光芒
- 代表「手动维护 Skill 太累」的普通用户

### 哆啦A梦 Doraemon — 技术导师
- 蓝色机器猫，白肚皮，四维口袋，红鼻子，金铃铛
- 从口袋掏出「概念可视化道具」解释 Agent 架构
- 耐心、用动作演示而非黑板讲解

### 龙虾君 OpenClaw — 象征 OpenClaw
- 可爱红色龙虾 mascot，戴小工牌「ClawHub」
- 身后是巨大超市货架（上万 Skill）
- 手里拿着 MEMORY.md 和 SOUL.md 文件夹

### 爱马仕君 Hermes — 象征 Hermes Agent
- 优雅黑马 mascot，颈戴金色 H 徽章
- 身侧有自动 Skill 工厂流水线
- 轻量、灵动，带 MIT 开源标志

### 静香 Shizuka — 澄清视角
- 黑发短发，粉色连衣裙
- 提出关键澄清问题（「那记忆呢？」「能一起用吗？」）
