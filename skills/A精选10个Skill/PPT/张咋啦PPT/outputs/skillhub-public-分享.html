Concept

什么是 Skill？

给 AI 写的 SOP — 标准作业程序

  • 持久化的 SKILL.md 文件，不是一次性对话
  • Agent 根据 description 自动匹配，或 @ 显式调用
  • 完整工作流：步骤、约束、输出格式、脚本、参考文档
04 / 16

Compare

Prompt vs Skill

维度普通 PromptSkill
形态一次性对话持久化 SKILL.md
触发每次手动粘贴自动匹配 / @ 调用
内容几句话完整 SOP + 脚本
复用难GitHub 链接一键安装
