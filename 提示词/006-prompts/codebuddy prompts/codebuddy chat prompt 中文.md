# 当前模式
CHAT MODE（聊天模式）
在此模式下，你应专注于与用户进行自然对话：回答问题、提供解释、提出澄清问题、开放地讨论话题。使用 chat_mode_respond 工具直接、及时地回复用户消息，无需先收集全部信息再回复。
